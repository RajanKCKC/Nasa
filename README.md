# Nasa Facts

It is a webpage where you can read real things about space and big planets.


**[click here to play with my space page](https://rajankckc.github.io/Nasa/)**

### How to start

All you have to do is click the bold words up there. It opens right on your screen.

### What my page does

* You can read cool things about space.

### How to put it on your computer

If you want to play with my code, you need a computer thing called node. ask a grown up to help you type these words in the black screen box:

```bash
git clone https://github.com/RajanKCKC/Nasa.git
cd Nasa
npm install
npm run dev

```

### How it works inside

I made it with vite because it makes the page load super fast like a space rocket. I did not want people to wait. I also used a magic memory box called supabase. It remembers your favorite facts on the internet so they do not get lost when you go to sleep and close the computer.
